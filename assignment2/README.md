## Element 1 — Creating the Dataset

### Data Description

`src/create_data.Rmd` constructs a dataset of **52 Danish monarchs**, covering the period from approximately the tenth century to the present. The dataset records each monarch's name, royal house, birth and death years, and the beginning and end of their reign.

The data were manually extracted from the historical sources listed below and encoded as a tibble in R. Because the dataset is relatively small, manual extraction provided a transparent way of constructing the dataset for this assignment. For a larger historical dataset, a reproducible method of structured data extraction would be preferable where the source permits it, as this could reduce manual transcription and facilitate updates to the dataset.

The initial dataset is exported as:

- `data/danish_monarchy.csv`

The script then creates reproducible identifiers for both monarchs and royal houses. `monarch_id` is generated by converting names to lowercase and replacing whitespace with underscores. Roman numerals are retained as lowercase letters (e.g., `Christian IV` → `christian_iv`), distinguishing monarchs who share the same regnal name.

Similarly, `house_id` is derived from `monarch_house` by converting the text to lowercase, removing commas, and replacing whitespace with underscores.

The resulting cleaned dataset is exported as:

- `data/monarchy_data.csv`

The cleaned dataset contains **52 observations and 8 variables**:

- `monarch_name`
- `monarch_id`
- `monarch_house`
- `house_id`
- `date_birth`
- `date_death`
- `start_reign`
- `end_reign`

### Missing Data

Missing values were retained where they represent unavailable or structurally incomplete historical information rather than data-entry errors.

For example, the beginning of Gorm the Old's reign is unavailable in the dataset, while the end of Frederick X's reign is necessarily missing because his reign is ongoing. These observations are therefore retained as `NA` and excluded only from analyses requiring a complete reign period.

The same principle is applied to missing birth and death years: observations remain in the complete dataset and are omitted only when an analysis requires the corresponding variable.

### Sources

- [Britannica: List of Danish Monarchs](https://www.britannica.com/topic/list-of-Danish-monarchs-2061262), accessed 03/08/2026.
- [Wikipedia: List of Monarchs of Denmark](https://en.wikipedia.org/wiki/List_of_monarchs_of_Denmark), accessed 03/08/2026. Used particularly for birth years and royal houses.

Additional historical sources used to contextualize the analysis in Element 2 are documented in `references.bib` and cited using Chicago Notes and Bibliography style.

**Note:** Some historical birth dates are unknown or reported as ranges. Where a range is given, the earliest year is used in this dataset.

### Citation Style
References used in the analysis are stored in `references.bib`. The `chicago-fullnote-bibliography.csl` file is used to render citations according to Chicago Notes and Bibliography style.

## Element 2 — Analysis and Visualization

The full analysis for Element 2 is contained in `src/monarchs_DAM.Rmd`.

The cleaned `monarchy_data.csv` dataset is imported using the `tidyverse`. The assignment first compares different CSV-import functions and examines how R interprets the structure and data types of the file.

The subsequent analysis:

- calculates each monarch's duration of reign;
- examines and handles missing start- and end-of-reign values;
- calculates the average duration of reign;
- identifies monarchs whose reigns were longer than average;
- identifies the three longest-ruling monarchs;
- approximates reign duration in days; and
- visualizes the development of reign duration over time using `ggplot2`.

The analysis makes use of piping with `%>%` and `dplyr` functions such as `mutate()`, `filter()`, `select()`, `summarise()`, `arrange()`, and `slice()`.

### Reign Duration

Reign duration is calculated as:

```r
duration = endReign - startReign
```

Two monarchs lack sufficient information for this calculation and are retained as `NA`.

Among monarchs with complete reign information, the mean duration of reign is **21.16 years**. A total of **25 monarchs** have reign durations above this average.

The three longest reigns represented in the dataset are:

1. **Christian IV** — 60 years
2. **Margrethe II** — 52 years
3. **Christian IX** — 43 years

### Long-Term Trend

To examine reign duration historically, a `midyear` variable is calculated as the midpoint between the beginning and end of each reign:

```r
midyear = startReign + (endReign - startReign) / 2
```

This allows each reign to be represented by a single temporal position. Reign duration is then plotted against this midpoint, with monarchs distinguished by royal house and a smoothed line added to visualize the long-term trend.

## Outputs

Two figures are generated and saved in `out/`:

- `over_average_reign.jpg` — monarchs whose reign durations exceed the dataset average, grouped by royal house.
- `long_term_plot.jpg` — duration of reign through time, represented using the midpoint of each reign and a smoothed long-term trend.
